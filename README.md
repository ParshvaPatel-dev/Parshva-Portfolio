# Parshva | Freelance Web Developer & UI Designer Portfolio

> "I build websites that grow your business"

A bespoke, production-grade personal portfolio website crafted for **Parshva**, a freelance web developer and UI designer based in **Ahmedabad, Gujarat, India**.

---

## Architecture & Design Highlights

- **Modern Clean Light Theme**: Elegant light surfaces (`#f8fafc` background, crisp white `#ffffff` cards), electric indigo accents (`#4f46e5`), deep slate typography (`#0f172a`), and subtle 1px slate borders.
- **Editorial Centered Hero**: High-impact headline, status indicator, core tagline, and proof metrics bar without clutter.
- **Zero Emojis & Zero Raw Code**: Completely free of artificial code snippets, cartoonish emojis, and generic AI tropes.
- **Services & Offerings (Without Fixed Prices)**:
  - **Basic Website (Starter)**: 3-5 pages, mobile-responsive, contact form, WhatsApp quick-chat, fast turnaround.
  - **Standard Website (Growth - Recommended)**: 5-8 pages, bespoke UI/UX design, micro-animations, on-page SEO, speed optimization.
  - **Premium Web Application (Enterprise)**: Full custom web apps, e-commerce & payment gateways, CMS/admin dashboard, API integrations.
- **Selected Work (Featured Live Projects)**: Showcasing **Ibex Adventure** (`https://ibex-adventure-updated.vercel.app/`) and **GeM Verify** (`https://gem-verify-ten.vercel.app`) with authentic browser window mockups, high-resolution preview graphics, clean typography, and direct live links.
- **Core Principles (Why Work With Me)**: Fast Delivery, Premium Quality, Mobile First, Client Focused.
- **Client Testimonials**: Verified founder reviews with 5-star rating badges (Rahul Shah, Priya Mehta, Amit Patel).
- **Direct Inquiries (Contact)**: Interactive form with real-time validation, WhatsApp direct chat buttons, and 1-click email copy.
- **Floating Controls**: Persistent floating WhatsApp button and back-to-top button.
